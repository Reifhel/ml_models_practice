# Machine Learning Models Practice

A collection of Machine Learning models and exercises developed during courses from [Rocketseat](https://www.rocketseat.com.br?utm_source=chatgpt.com).

This repository is organized to separate:

- **Class implementations** — models and examples built during lessons.
- **Challenges** — practical exercises proposed to reinforce the concepts learned.

The goal of this project is to practice different Machine Learning techniques, improve understanding of data analysis workflows, and build a personal reference repository for future studies.

## Repository Structure

```bash
ml_models_practice/
│
├── 01. model_name/
│   ├── <name_of_the_model>/
│   │   └── ... files developed during classes
│   │
│   └── challenge/
│       └── ... challenge solutions
│
├── 0n. another_model/
│   ├── <name_of_the_model>/
│   └── challenge/
│
└── README.md
```

Each folder represents a different Machine Learning model or topic.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Reifhel/ml_models_practice.git
```

2. Access the project folder:

```bash
cd ml_models_practice
```

3. (Optional) Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the environment:

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```
