# Instructions

###### _Project Structure, Rules, and Requirements_

The goal of this exercise is to build a machine learning model capable of predicting a property's rent based on its characteristics. By analyzing a dataset of properties, you will:

1. Explore the data: Perform an exploratory analysis of the data to understand the distribution of variables, identify potential outliers, and detect correlations.
2. Prepare the data: Clean the data, handle missing values, and encode categorical variables.
3. Build a model: Use a linear regression algorithm to build a model that relates property characteristics to the rent amount.
4. Evaluate the model: Evaluate the model’s performance using appropriate metrics and analyze the residuals to assess the quality of the predictions.
5. Interpret the results: Analyze the model coefficients to understand the importance of each variable in predicting the rent.

## Tasks

Use this checklist to help organize your delivery

- [ ] Load the provided CSV file using pandas
- [ ] Explore the data using pandas functions
- [ ] Identify and handle missing values in the dataset
- [ ] Remove outliers that could compromise the model
- [ ] Encode categorical variables
- [ ] Scale the numerical variables (if necessary)
- [ ] Split the data into training and test sets
- [ ] Create a pipeline to preprocess the data
- [ ] Train the linear regression model using the training set
- [ ] Make predictions about the test set
- [ ] Calculate performance metrics (R², MAE, RMSE)
- [ ] Analyze the residuals to verify the quality of the model
- [ ] Analyze the model's coefficients and discuss its limitations and potential improvements
