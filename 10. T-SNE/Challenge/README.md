# Instructions

###### _Project Structure, Rules, and Requirements_

Apply the t-SNE algorithm to reduce the dimensionality of the gene expression data (50 dimensions) to 2 dimensions.

After the reduction, generate two plots: a 2D plot using the first two components of the t-SNE and a 3D plot using the first three components.

- In the 2D plot, use component 1 on the X-axis and component 2 on the Y-axis.
- In the 3D plot, use component 1 on the X-axis, component 2 on the Y-axis, and component 3 on the Z-axis.
- In both plots, the color of the points should represent the cell_type attribute.

After visualizing the data, perform a visual analysis to verify whether the different cell types form clear and distinct clusters in the projected space.
