# Instructions

###### _Project Structure, Rules, and Requirements_

Your challenge is to develop a complete irrigation data analysis system using Python and data science libraries. The goal is to create an analysis pipeline that allows you to load data, perform exploratory analysis, build predictive models, and evaluate results to optimize the use of water resources on the farm.

Below you will find some important steps you must follow to ensure the challenge meets the requirements!

## Tasks

Use this checklist to help organize your delivery

- [ ] Load irrigation data from a CSV file
- [ ] View the data to understand its structure and the available variables
- [ ] Calculate the descriptive statistics for the variables
- [ ] Create scatter plots to visualize the relationship between irrigation hours and irrigated area by angle
- [ ] Analyze the correlation between the variables
- [ ] Split the data into training and test sets
- [ ] Train a linear regression model using irrigation hours as the independent variable (X) and area irrigated per angle as the dependent variable (Y)
- [ ] Print the equation of the line obtained by the model
- [ ] Use performance metrics (MSE, MAE) to evaluate the model's accuracy
- [ ] View the actual and predicted results in a graph
- [ ] Calculate and analyze the model's residuals
- [ ] Check whether the residuals follow a normal distribution using statistical tests and graphs
- [ ] Use the model to make predictions (e.g., predict the irrigated area by angle for 15 hours of irrigation)

## Note

The dataset is compressed in the resources section; you must extract it first.
