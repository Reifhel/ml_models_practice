# Instructions

###### _Project Structure, Rules, and Requirements_

Build a classification model using the Random Forest algorithm to predict loan approval, based on the provided dataset.

Use the 13 available predictor variables to train the model and classify the target variable `loan_status`, which indicates whether the loan was approved (1) or rejected (0).

The dataset contains 45,000 records and 14 variables, including detailed information on age, gender, education level, income, work experience, housing status, loan amount and purpose, interest rate, loan-to-income ratio, length of credit history, credit score, and previous delinquency records.

Perform all necessary steps to prepare the data, train, validate, and evaluate the models performance, ensuring the appropriate use of the available information.

## Dataset

[Kaggle: Loan Approval Classification Data](https://www.kaggle.com/datasets/taweilo/loan-approval-classification-data/data)

Dataset description:

- Synthetic data based on an original credit risk dataset.
- Expanded with additional variables related to financial risk.
- Contains 45,000 records and 14 variables, including the target variable \`loan_status\`.
