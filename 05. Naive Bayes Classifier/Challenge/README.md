# Instructions

###### _Project Structure, Rules, and Requirements_

Build a classification model using the Naive Bayes algorithm to predict whether a patient has diabetes, using the provided dataset.

### Dataset:

The dataset contains 995 entries and 3 columns:

`blood_glucose:` Blood glucose level.
`blood_pressure:` The patients blood pressure.
`diabetes:` Target class, where 1 indicates that the patient has diabetes and 0 indicates that they do not.

## Tasks

Use this checklist to help organize your delivery

- [ ] Load the dataset containing the columns “blood_glucose",“blood_pressure", and "diabetes" with 995 entries.
- [ ] Preprocess the data, if necessary.
- [ ] Implement the Naive Bayes classification algorithm.
- [ ] Train the model using the data from the dataset.
- [ ] Evaluate the model's performance in classifying patients.
- [ ] Present the results obtained.

The dataset is compressed in the resources section; you must extract it first.
